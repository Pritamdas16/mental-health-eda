# mental-health-eda
# Mental Health in the Tech Workplace — EDA

## Project Overview
Exploratory Data Analysis on the OSMI Mental Health in Tech Survey (2014) 
dataset containing 1,259 responses from tech industry employees.

## Dataset
- 1,251 rows × 27 columns (after cleaning)
- Source: Open Sourcing Mental Illness (OSMI)
- Target Variable: `treatment` (Yes/No)

## Key Findings
- 50.5% of tech employees sought mental health treatment
- Family history is the strongest predictor (76.2% vs 30.7%)
- 35% fear negative consequences for disclosing mental health issues
- Males significantly less likely to seek treatment (47.4%) vs Females (62.8%)

## Tools Used
- Python, Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn (Label Encoding)
- Jupyter Notebook
